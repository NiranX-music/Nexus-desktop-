The Complete Nexus Macros & Timely Automations Manual

Welcome to the official developer and operator guide at /nexusai/macro/docs. Learn how to craft multi-step cross-device pipelines, configure precision cron expressions, tap into dynamic runtime variables, and orchestrate automated AI workflows.

1. Core Architecture

How Nexus Macros Work

A Macro is an ordered chain of execution steps. When triggered (by a cron timer, hotkey, webhook, or system event), it evaluates conditions, interpolates dynamic tokens, and dispatches instructions across Cloudflare Edge, Win32 Desktop, or Android Termux.

• Deterministic: sequential dependency
• Zero-Card: powered by D1 & KV
• Resilient: auto-retry failover
2. Timely Automations

Precision Scheduling Engine

Automate tasks on continuous schedules. Use 5-field standard cron expressions (min hr dom mon dow), interval loop timers, or one-shot countdown triggers. Built-in drift compensation guarantees time accuracy.

• CRON: 30 8 * * * (Daily 8:30 AM)
• INTERVAL: Every 15 min / 1 hour
• ONE-SHOT: Run once in 30 minutes
3. Dynamic Variables

Runtime Context Tokens

Enrich steps with dynamic real-time data using curly tokens: {date}, {timestamp}, {battery_pct}, {clipboard}, {device_name}, and chain outputs via {step_1_output}.

• {timestamp}: ISO 8601 current time
• {battery_pct}: Current battery 0-100%
• {step_N_output}: Preceding step stdout
