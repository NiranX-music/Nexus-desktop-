60-Second Quickstart

Here is how to define, register, and trigger a simple macro with timely execution in under one minute:

quickstart-macro.json 
{
  "id": "macro_daily_morning_brief",
  "name": "Daily Morning AI Intelligence Brief",
  "description": "Gathers device telemetry, summarizes pending tasks, and displays morning notification",
  "schedule": {
    "type": "CRON",
    "expression": "30 8 * * *",
    "timezone": "Local",
    "enabled": true
  },
  "steps": [
    {
      "step_id": 1,
      "type": "D1_QUERY",
      "target": "CLOUD",
      "params": {
        "query": "SELECT count(*) as pending_tasks FROM tasks WHERE status = 'QUEUED'"
      }
    },
    {
      "step_id": 2,
      "type": "AI_REASON",
      "target": "CLOUD",
      "params": {
        "prompt": "Create an uplifting 2-sentence morning briefing for NiranX. Date: {date}, Pending Tasks: {step_1_output}"
      }
    },
    {
      "step_id": 3,
      "type": "NOTIFY",
      "target": "DESKTOP",
      "params": {
        "title": "Nexus Morning Briefing",
        "message": "{step_2_output}",
        "chime": true
      }
    }
  ]
}

Timely Automations & Scheduler Engine

Nexus includes an intelligent, drift-compensated scheduling engine. Unlike traditional browser timers that throttle when tabs lose focus, the Nexus Scheduler utilizes Web Workers and background heartbeat sync combined with Cloudflare Edge cron triggers.

Schedule Mode Pattern Format Behavior Ideal Use Cases
CRON m h dom mon dow Fires at precise wall-clock times matching 5-part cron syntax Daily morning reports, midnight backups, weekday alarms
INTERVAL every N min/sec Repeats continuously with drift correction every interval Fleet ping sweeps, telemetry polling, battery safeguard
ONE_SHOT ISO 8601 or delay Fires once at future time or after countdown, then disables Delayed compilation, timed reminders, meeting follow-ups
EVENT_BOUND ON_BATTERY_LOW Fires when device telemetry state breaches threshold Auto-power saver, critical system alerts, Wi-Fi disconnect

Dynamic Tokens & Context Variables

Any macro step prompt or command can reference live system context via double curly braces {token}. The engine interpolates them immediately prior to step dispatch:

{timestamp}
ISO 8601 current UTC timestamp
Output: 2026-10-12T22:30:00Z
{date} / {time}
Local formatted date and 24h clock
Output: 2026-10-12 / 22:30:00
{device_name} / {device_id}
Target node identifier and host name
Output: PC-NIRANX-WORKSTATION
{battery_pct}
Mobile / Laptop current battery level (0-100)
Output: 92%
{step_N_output}
Output stdout/result from preceding step N
Allows chaining AI outputs into shell scripts
{user_email}
Master account authenticated email
Output: barhateniranjan725@gmail.com

Action Steps Catalog

Nexus provides 8 fundamental action primitives. Each step executes on its assigned target and returns its structured payload to the pipeline:

AI_REASON Gemini 3.8 / Workers AI Prompt Inference

Executes multimodal or text prompt, formats output, generates code or JSON structures.

Target: CLOUD
SHELL_EXEC Native Terminal & PowerShell / Bash Execution

Runs command in daemon sandbox with stdout/stderr capture and exit code checks.

Target: DESKTOP
DESKTOP_GUI Win32 GUI Automation, Hotkeys & Screenshots

Simulates keyboard shortcuts (e.g. WIN+D, CTRL+SHIFT+ESC) or captures screen frame.

Target: DESKTOP
MOBILE_TERMUX Android Termux System Call & Sensor Sweep

Termux API intent commands: vibration, toast, sensor queries, battery level.

Target: MOBILE
D1_QUERY Cloudflare D1 Serverless SQLite Edge Query

Zero-Card database read/write query with parameterized bindings.

Target: CLOUD
NOTIFY Desktop / Web Push Notification & Web Audio Chime

Displays native notification card and synthesizes synthesized audio chime.

Target: ALL

REST API & Webhook Trigger Reference

You can trigger any macro remotely from GitHub Actions, curl scripts, Python backend services, or webhooks:

POST /api/macros/run (Cloudflare Edge) 
curl -X POST "https://ecosystem-landing.pages.dev/api/macros/run" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer NEXUS_SECRET_KEY" \
  -d '{
    "macro_id": "macro_daily_morning_brief",
    "trigger_source": "WEBHOOK_EXTERNAL",
    "params": {
      "priority": "HIGH"
    }
  }'
