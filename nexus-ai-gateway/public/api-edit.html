Configure Nexus Servers

Add NVIDIA_API_KEY as an environment variable on every Vercel and Netlify mirror. NVIDIA_BUILD_API_KEY and NVIDIA_NIM_API_KEY are accepted as aliases. The key is never stored in this browser page. 

NVIDIA_API_KEY=nvapi-your-key
NEXUS_ADMIN_PASS=05122010
NEXUS_ALLOW_PUBLIC_AI=false

Deploy the same project to three Vercel sites and three Netlify sites. The desktop app rotates across all mirrors automatically.
