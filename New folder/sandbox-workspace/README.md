# Nexus Isolated Sandbox Workspace

This folder is the dedicated, isolated containment area for Nexus Desktop operations.

## Security Guarantees:
- **Filesystem Isolation**: When Nexus Sandbox Shield is enabled, all file writes, patches, deletions, and moves generated by autonomous agents are jailed here.
- **Host PC Protection**: Files outside this directory (such as `C:\Windows`, `C:\Users\...\Documents`, `Desktop`, system files, and app data) are protected from alteration.
- **Clean Git Tracking**: Everything inside this directory (except this README and .gitignore) is ignored by git so test executions do not pollute the repository.
